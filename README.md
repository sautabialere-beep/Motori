# Motori

Sito statico (HTML, CSS, JavaScript) pubblicato con GitHub Pages.

## Come modificare i testi del sito
I testi visibili sul sito si trovano nella cartella `contenuti/` (per esempio
`contenuti/home.txt`). Puoi aprire quei file con un normale editor di testo
(es. Blocco Note) e modificarli: non serve saper programmare.

Ogni riga vuota nel file crea un nuovo paragrafo nella pagina.

## Come vedere le modifiche
Le modifiche sono visibili online dopo il push su GitHub, tramite
GitHub Pages. Per provare il sito sul proprio computer prima di pubblicarlo,
serve un piccolo server locale (il semplice doppio clic su `index.html`
potrebbe non caricare i testi, per via delle regole di sicurezza del
browser).

Le regole tecniche complete del progetto sono in [CLAUDE.md](CLAUDE.md).
